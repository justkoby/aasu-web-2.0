# AASU Website 2.0 — Modern Continental

Official website redesign for the **All-Africa Students Union (AASU)**.

## Tech Stack
- **React 19** + **TypeScript** + **Vite 6**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **Framer Motion** (`framer-motion`) with `reducedMotion="user"`
- **Lucide React** (`lucide-react`)

## Brand Identity
- **AASU Red:** `#cb3631` (Hover/Dark: `#992d29`, Vivid Logo Red: `#e63428`)
- **Black:** `#121212`
- **White:** `#ffffff`
- **Off-white:** `#f5f5f5`
- **Typography:** Manrope (Headings) & Inter (Body)

## Development
```bash
npm install
npm run dev
```

## Checks
```bash
npm run typecheck
npm run lint
npm run build
```

## Branching
- `main`: Initialised baseline / release branch (do not develop directly on `main`).
- `staging`: Active development branch for Phase 1 and upcoming features.
